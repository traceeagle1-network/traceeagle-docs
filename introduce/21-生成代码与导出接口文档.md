# 生成代码与导出接口文档

> 抓到的请求不止能看——还能**直接变成产物**：一条请求一键转成能跑的**代码**（5 种语言），一整段会话自动归并成规范的**接口文档（OpenAPI）**，或导出为通用的 **HAR** 交换格式。都是从真实抓包直出，不用手抄、不用手写；别处抓的会话也能导进来接着分析。

---

## 一、生成代码：一条请求变成能跑的代码

抓到一条想复现或分享的请求，一键把它变成**可直接运行的代码**——粘进终端、贴进工程、发给同事都省事。

**5 种形式**，切换语言即时重新生成、一键复制：

- **cURL**（贴进终端就能跑）
- **Python**
- **JavaScript**
- **Go**
- **OkHttp**（Java / Kotlin）

生成的代码是**完整**的：请求方法、URL、**全部请求头、请求体**一应俱全。而且请求头**保持原顺序、允许重复**——顺序和重复项都原样保留，复现更保真，拿去即可原样跑起来。

![生成代码：cURL / Python / JavaScript / Go / OkHttp 五种形式切换，含完整方法、请求头与请求体，一键复制](img/21-generate-code.png)

> 普通工具生成代码常把请求头**重排、去重**，复现就走样了；这里**原样保留**，跑出来和真实请求一致。

**从哪里生成**

- **抓包列表**：右键任意一条请求 →「生成代码…」。
- **请求构造器**：在 [请求构造与重放](02-请求构造与重放.md) 里调好一个请求后，点「生成代码」。

**什么时候用**：把抓到的真实请求复现到脚本 / 工程；在构造器里调通一个请求后导出成代码接着开发；把一条请求分享给同事（一条 cURL 谁都能跑）。

## 二、导出接口文档：一段会话变成 OpenAPI

抓完一段接口流量，想要一份规范的接口文档？它会**自动整理**这些请求、归并出接口清单，一键生成 **OpenAPI** 文档——不用手写。

- **先分析、再导出**：从当前会话**自动识别出接口**，列成清单让你勾选，只导你选的、避免噪声。清单直接显示每个接口的**方法、路径、出现次数、见过的状态码**，一眼看清接口全貌。
- **自动归并路径**：把带具体 ID 的路径模板化，例如 `/users/123` → `/users/{id}`，相同接口的多次请求合并成一条。
- **自动推断结构**：合并请求 / 响应的 JSON 结构、按状态码归类响应、把路径变量整理成参数。
- **产出标准 OpenAPI 3.0**：可**复制**或**下载**，导入任何支持 OpenAPI 的接口工具继续使用。

![导出 OpenAPI：左侧勾选接口（含方法 / 路径 / 出现次数 / 状态码），右侧实时预览自动推断出的 OpenAPI 3.0 文档](img/21-openapi.png)

**什么时候用**：抓完接口流量，想快速产出一份可交付、可导入的 OpenAPI 文档；逆向分析、对接第三方接口、给后端补文档、给测试造用例。

---

## 三、导入与导出：和别的工具互通

抓到的流量不锁在这里，别处抓的也能拉进来——一套标准的会话交换格式打通两头：

- **导出 HAR**：整段抓包一键导出为标准 **HAR 1.2** 文件，交付、归档、或转给别的工具接着分析都行。
- **导入他人抓的会话**：把外部抓包会话文件（HAR 1.2、`.pcap` / `.pcapng`，以及常见抓包工具导出的会话文件）**导入进来**——别人抓的包也能拉进来接着看、接着比、接着导。

**什么时候用**：把线上 / 同事 / 其它工具抓到的流量拿到这里，借它的解码、主机档案、请求对比继续分析；或把本工具抓到的一段流量导出成通用格式交付出去。
