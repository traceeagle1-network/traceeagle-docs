# 数据查看与解码

> 抓到只是第一步，**看懂**才是关键。普通工具经常甩给你一堆压缩字节或乱码；TraceEagle 会自动解压、自动识别格式、自动美化，还能内联预览媒体、拆解私有协议——让每一条数据都以最易读的样子呈现。

---

## 一、一条数据，五种看法

请求与响应两侧**各自独立**切换查看方式：

- **结构化**：起始行 + 请求头表格 + 智能 body，默认视图。
- **文本·美化**：按内容类型自动缩进——JSON、XML、表单（`x-www-form-urlencoded`）一键格式化易读。
- **文本·原样**：完整报文按文本原样展示。
- **十六进制**：hex 查看器，可点击字节 hex↔ASCII 联动高亮、显示偏移、一键保存为二进制文件；超大数据也能流畅查看、不卡顿。
- **自动识别**：交给引擎深度解码，渲染成可逐层展开的解码树——压缩里套压缩、帧里套帧都能一层层钻进去。

![查看方式切换：结构化 / 文本·美化 / 文本·原样 / 十六进制 / 自动识别，请求与响应各自独立切换](img/05-view-as.png)

> 「查看为」只切换**表示层**（结构化 / 文本 / 十六进制 / 自动识别）；JSON、XML、表单属于文本的格式化方式，由「文本·美化」自动处理，不单列。

![十六进制查看器：显示偏移，hex 与 ASCII 并排联动，可一键保存为二进制文件](img/05-hex.png)

## 二、引擎自动帮你做的事

- **自动解压**：gzip、brotli(br)、deflate、zstd，支持多层叠加编码（如 `gzip, br` 从外到内逐层解）——普通工具往往只解最外一层。
- **自动识别并美化**：JSON、XML、表单、Apple plist（二进制 / XML / NSKeyedArchiver 归档还原）、protobuf / gRPC。
- **二进制格式识别**：内置自研数据识别引擎，自动认出图片、字体、PDF、压缩包等，并能列出压缩包内的文件清单。
- **媒体内联预览**：图片、视频、音频直接在详情里预览 / 播放。
- **信封智能剥离**：识别遥测上报常见的「自定义头 + 压缩流」信封（往往没有标准编码标识），自动剥离信封头、还原出真实数据——普通工具到这里就是一堆乱码。
- **诚实的失败提示**：遇到确实无法还原的私有加密数据，会**明确说明情况，而不是丢一堆乱码给你**。
- **统一 UTF-8**：字符编码统一处理为有效 UTF-8。

![媒体内联预览：图片直接在响应详情里渲染，并标注类型与大小](img/05-image-preview.png)

## 三、不止 HTTP body

| 数据类型 | 查看方式 |
| --- | --- |
| **WebSocket** | 逐帧展示（文本 / 二进制 / ping / pong），标注收发方向 |
| **Server-Sent Events (SSE)** | 事件流逐事件展示 |
| **gRPC / protobuf** | 无需 `.proto` 即可解出字段号 / 类型 / 值 |
| **裸 TCP / UDP** | 未解密或非 HTTP 的原始收发字节，hex / 文本切换查看 |

---

## 四、私有协议也能拆

面对非 HTTP 的私有 / 二进制协议：

- **很多私有帧不用配就能自动拆**：引擎会自动试出常见的定长前缀边界并逐帧展开——不写任何脚本，一条裸流也能拆成一条条消息。
- **内置分帧模板**：长度前缀、Magic 签名边界、分隔符（可含 hex）、定长等常见私有帧结构都有**开箱模板**，改几个值就能拆；再复杂的结构用下面的 JS 脚本兜底。
- **JS 脚本解码**：写少量 JavaScript 自定义分帧与解码逻辑，内置取字节、进制转换、解压等常用辅助能力，开箱即用。
- **手动「Decode As」**：对任意一条连接手动选择分帧方式，查看整条收发时间线，每条消息还能再切自动识别 / 文本 / hex。详见 [自定义协议解码](20-自定义协议解码.md)。
