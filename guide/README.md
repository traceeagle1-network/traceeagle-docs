# 使用教程

> TraceEagle 的**使用教程**：手把手教你「怎么一步步操作把事情做成」——从装好启动、选对抓法、装证书解密，到看懂数据、改写重放、用好网络工具箱。每篇都是可照做的步骤，配验证与排错。
>
> 只想了解「有哪些功能、比普通工具强在哪」，看功能介绍文档（`doc/introduce/`）；想动手做，就从这里开始。

---

## 从这里开始

**第一次用**，先看 [快速开始](01-快速开始.md)：几分钟跑通一次抓包，抓下并看懂第一条解密请求，再挑一条适合你目标的抓法。

## 一、选抓法：把流量抓下来

对着目标挑一种抓法：

| 教程 | 抓什么 |
| --- | --- |
| [代理抓包](02-代理抓包.md) | 本机 / 手机 / 局域网设备，经典代理 + 解密，还能改包重放 |
| [网卡抓包](03-网卡抓包.md) | 整机全部流量，含不走代理的、UDP / QUIC、DNS |
| [指定程序抓包](04-指定程序抓包.md) | 只抓某一个程序，自动解密、免证书、零干扰 |
| [应用层抓包](05-应用层抓包.md) | 证书绑定 / 自研加密 / 系统加密库，从程序内部取明文 |
| [系统级抓包](06-系统级抓包.md) | macOS 系统自带 App、顽固应用 |
| [iOS 抓包](07-iOS抓包.md) | iPhone / iPad，非越狱 USB 接入 |
| [Android 抓包](08-Android抓包.md) | 安卓整机 / 单 App 多种方式 |

## 常见路径速查

- **想立刻看到明文** → [指定程序抓包](04-指定程序抓包.md)
- **抓手机 App** → [iOS 抓包](07-iOS抓包.md) / [Android 抓包](08-Android抓包.md)，配合 [证书安装](09-证书安装.md)
- **抓到了但全是密文** → [证书安装](09-证书安装.md)，仍不行看 [解除证书绑定](10-解除证书绑定.md) 或 [应用层抓包](05-应用层抓包.md)
- **一条都没抓到** → [网卡抓包](03-网卡抓包.md)，或先跑 [网络诊断](19-网络诊断.md)
- **要改请求 / 重放 / 压测** → [规则改写与断点拦截](16-规则改写与断点拦截.md)、[请求构造与重放](17-请求构造与重放.md)、[会话重放与压力测试](18-会话重放与压力测试.md)
