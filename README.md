## 核心能力

- **底层全量抓包**：网卡逐包直抓，DNS、QUIC、ICMP、ARP、任意 TCP/UDP 都不漏，粒度与 Wireshark 一致
- **代理精准抓包**：规则驱动解密代理，精准抓 HTTP/HTTPS/HTTP2/HTTP3/WebSocket/gRPC，支持改写与重放
- **应用内取明文**：绕过证书固定（pinning）与私有加密协议，直接从应用内部取明文，不依赖中间人证书
- **手机抓包**：iOS 免越狱、Android 免装证书，同一套界面和视图
- **抓到即自动解密**：不配代理、不手动导密钥、不装环境，会话密钥自动匹配，密文变明文
- **流量调试**：断点拦截、规则改写与 Mock、请求构造与重放、会话重放与压测（百分位到 p99.9）、请求对比、自定义协议解码、生成代码、导出 OpenAPI 接口文档
- **AI 集成**：内置 MCP 服务，40+ 个工具开放为 API（stdio / HTTP 接入），仅本机回环运行
